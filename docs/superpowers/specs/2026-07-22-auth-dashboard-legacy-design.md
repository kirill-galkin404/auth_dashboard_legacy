# Дизайн: auth_dashboard_legacy

**Дата:** 2026-07-22
**Статус:** Утверждён

## Цель

Тестовый проект для эксперимента по рефакторингу/переписыванию легаси. Намеренно
написан в «старом» стиле, чтобы было что улучшать. Приоритет — чтобы работало, а не
чистая архитектура.

## Стек

- **Фронт:** AngularJS 1.x (классический, из CDN, без сборщика)
- **Бэк:** Node.js + Express в старом стиле (один `app.js`, `var`, callbacks)
- **БД:** SQLite (файл)
- **Авторизация:** сессии на cookie (`express-session`)
- **Дашборд:** KPI-карточки + таблица, данные генерятся бэком случайно

## Структура

```
/

│   ├── app.js          # ВСЁ: маршруты, логика, сессии
│   ├── db.js           # инициализация SQLite + сидинг юзеров
│   ├── package.json

└── README.md
```

## Бэкенд (нарочито легаси)

- Один `app.js`: `var`, callbacks, сырые SQL-строки, минимум обработки ошибок.
- Эндпоинты:
  - `POST /api/login` — проверяет логин/пароль по SQLite, ставит сессию в cookie.
  - `POST /api/logout` — рушит сессию.
  - `GET /api/me` — кто залогинен (для проверки на фронте). 401 если не залогинен.
  - `GET /api/dashboard` — требует сессию, возвращает случайные KPI + строки таблицы.
- Пароли хранятся plain text (легаси — будет что рефакторить).
- Сидинг: пользователь `admin` / `admin123`.
- Express отдаёт статику из `public/` и API — как в старых монолитах.

## Фронтенд (AngularJS 1.x)

- Angular + angular-route из CDN, никакого npm на фронте.
- Роуты `/login` и `/dashboard` через `$routeProvider`.
- `$http` к API, cookie летит автоматически.
- Простой гард: на `/dashboard` дёргаем `/api/me`, при 401 — редирект на `/login`.
- Дашборд: KPI-плитки (выручка, юзеры, заказы, конверсия) + таблица «транзакций».

## Поток данных

1. Логин → `POST /api/login` → сессия в cookie.
2. Angular редиректит на `#/dashboard`.
3. Dashboard-контроллер → `GET /api/dashboard` → бэк генерит рандом → рендер.
4. Logout → сессия рушится → редирект на логин.

## Осознанные «плохие» решения (материал для рефакторинга)

Plain-text пароли, SQL конкатенацией строк, вся логика в одном файле, `var`/callbacks,
нет валидации входных данных, глобальное состояние.

## Запуск

`cd server && npm install && npm start` → `http://localhost:3000`.
